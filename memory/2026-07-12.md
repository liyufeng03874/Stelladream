# 2026-07-12 星跃动画调优记录

## 概述
哥哥要求星跃（jumpToStar）的最终视觉效果和 query 搜索一致——星星大小、辉光、亮度、颜色完全相同。

## 核心发现

### Query vs 星跃 的数据对比（最终状态）
| | Query | 星跃 |
|---|---|---|
| trueOriginalScale | 0.12 × 0.12 × 1.0 | 0.453 × 0.453 × 1.0 |
| sprite 最终尺寸 | **0.6 × 0.6 × 5.0** | **0.6 × 0.6 × 5.0** ✅ 已统一 |
| 辉光数量 | **1 个，30×30** | **1 个，30×30** ✅ 已统一 |
| 辉光颜色 | 0x34D399（绿色） | 0x34D399（绿色）✅ |
| 材质 color | #ffffff | #ffffff ✅ |
| blending | AdditiveBlending (2) | AdditiveBlending (2) ✅ |

**所有参数完全一致，但视觉效果仍有差异——星跃的星星看起来仍然比 query 小。**

### 排查过程（按时间线）
1. **重复声明 bug**：`targetPos` 重复声明 → 修复
2. **流星不出现**：`flyToStar` 和 `shootMeteors` 同时执行，相机飞走流星才出现 → 改为等流星完成后再飞
3. **辉光尺寸错误**：错误计算 `30 * (origScale / 0.12)` = 113.3，远大于 query 的 30 → 改为固定 30
4. **两层辉光**：最初以为 query 有 113.3 外层 + 30 内层两层辉光 → 实际 query 日志显示只有 1 个 30 辉光
5. **辉光颜色**：星跃辉光 material.color 是白色（默认值），但实际颜色由 canvas 纹理决定，不影响最终颜色
6. **sprite 尺寸**：最初星跃 sprite 是 2.2（origScale × 5），query 是 0.6 → 统一为 0.6

### 未解决的问题
- 参数完全一致，但星跃视觉上仍然更小
- **可能原因**：相机距离不同。query 的星星离相机近，星跃的星星可能被 clamp(25,60) 的飞行距离限制导致相机更远
- **也可能**：辉光 canvas 纹理在不同位置/角度下的渲染效果不同
- **还需要继续排查**
