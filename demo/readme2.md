# 3D 星云/图谱：视觉对比分析与修复优化指南

## 📌 概述
右图（用户效果）当前看起来像“散落的蓝色芝麻粒”，而左图（我的效果）有星云感。
造成这种差异的核心原因不是“星星数量”的问题，而是**渲染层次、分布算法、混合模式以及后期特效**的缺失。

---

## 🔍 为什么右图显得“松散、没星云感”？（四大核心差异）

**1. 缺少“视觉引力核”**
*   **左图**：有极强的视觉中心。由于大量的星星聚集在半径极小的核心区域，形成高亮、高密度的光源。
*   **右图**：星星分布非常均匀（或者极度随机），没有明显的聚拢倾向，导致视觉涣散，没有焦点。

**2. 底层缺乏“星尘暗噪”**
*   **左图**：不仅有数百颗亮星，**底层还有 1.6 万个极微小的暗色星点**作为“宇宙粉尘”来填充空间缝隙。
*   **右图**：如果只生成了几百个数据节点且没有任何底层粒子补充，画面就会显得极度空旷，形成大片的黑色断层。

**3. 没有泛光特效（Bloom）**
*   **左图**：星星的边缘有柔和、克制的**光晕溢出**（犹如真实的恒星发光）。
*   **右图**：星星是**实心且边缘锐利**的圆点，没有任何发光或溢散效果，看起来像是直接画在黑色屏幕上的 2D 贴图。

**4. 星星没有融合（混合模式）**
*   **左图**：使用了 `THREE.AdditiveBlending`（叠加混合）。当星星重叠时，亮度会自动叠加变亮，自然地形成“高光”和“云团”感。
*   **右图**：可能是使用了默认的混合模式。星星是孤立的，即使靠得很近，也只是生硬地叠在一起，不会产生发光叠加效应。

## 🛠️ 怎么把右边改得和左边一样？（3步修复法）

### Step 1：加上“底层星场”（解决空旷感）
不要只绘制亮节点。在生成节点之前，先创建一个数量巨大（8000 ~ 16000 个）、尺寸极小（`size: 0.08`）、透明度极低（`opacity: 0.4`）的**暗色粒子系统**。
> **作用**：为画面铺上一层“星尘底噪”，让黑暗空间不再空洞。

### Step 2：让星星有“向心力”（解决中间不亮）
不要使用简单的 `Math.random() * radius`（这会随机均匀地铺满一个圆）。
改用**指数随机分布**，让星星在靠近 0 时出现概率更高：

// 推荐算法：让大部分节点偏向中心 0 点
