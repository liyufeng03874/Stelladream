# 🌌 3D 不规则星河 / RAG 知识图谱可视化

这是一个基于 Three.js 构建的**高质量 3D 粒子星云可视化网页**。
它模拟了一个拥有旋臂、厚度渐变、边缘参差不齐的扁平星系。底层由 1.6 万个清晰可见的粒子构成，中层包含 700 个亮色数据节点，同时保留了弱化的数据连接线。
该原型非常适合用于 **RAG (检索增强生成) 评估系统**的 3D 动态数据可视化。

## 📸 核心视觉效果特性

1. **清晰粒子替代模糊云团**：彻底放弃了低透明度的大尺寸粒子叠加，采用高数量（16000+）的小粒子，每颗星星独立清晰，解决了“糖霜饼干”和“马赛克云”的粗糙感。
2. **不规则且带有旋臂**：通过极坐标转换加入扰动参数(`noise`)和旋臂角度偏移(`armAngle`)，打破了僵硬的完美圆形，呈现出类似星系的自然旋转臂。
3. **无黑洞的星核**：取消了半径下限隔离，使星核和节点均匀地向 `radius = 0` 的绝对中心聚拢，视觉上没有任何突兀的黑孔。
4. **极扁平薄盘**：在 Y 轴上进行了极端的厚度压制（中心 0.6，边缘 0.05），使其在 3D 空间中呈现出“银河光碟”的视觉感受。
5. **暗化数据网格**：保留了 RAG 领域需要的特征（临近节点连接线），但将线条透明度降到了 `0.015`，使其完全隐入星空中，仅提供若隐若现的数据关联暗示。

## 🛠️ 技术栈
- **Three.js** (3D 引擎)
- **OrbitControls** (鼠标控制 & 自动旋转)
- **UnrealBloomPass** (后期特效与泛光)

## ⚙️ 快速配置指南 (如何修改银河)

你可以直接在 `index.html` 代码的最上方（`<script type="module">` 标签内的开头）修改以下参数，来调节星河的视觉表现：

| 参数/行数位置 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `controls.autoRotateSpeed` | `0.45` | **旋转速度**。越小转得越慢，比如 `0.2` 会出现极静谧的太空感。 |
| `camera.position.set` | `22, 12, 22` | **相机初始距离**。把 `22` 改小（如 `16`）相机拉近，星河会显得更大更震撼。 |
| `starFieldCount` | `16000` | **底层星场数量**。越高星星越密集，但会稍微影响性能。 |
| `nodeCount` | `700` | **上层数据节点数量**。用于表示 RAG 检索出的数据点。 |
| `bloomPass` 强度 | `0.15` | **泛光强度**。如果希望星星更刺眼更亮，调高到 `0.3` 左右。 |

## 💻 运行说明
该工程使用现代 JavaScript 的 **Import Map** 引入依赖，**不需要**安装 Node.js、Vite 或 Webpack。
1. 将提供的 HTML 代码保存为 `index.html` 文件。
2. **直接双击**该 HTML 文件，它会在默认浏览器中自动打开并运行。
3. 使用鼠标左键**拖拽**可以旋转视角，**滚轮**可以进行缩放。

## 🚀 扩展开发建议：对接 RAG 数据
由于您已经调试出清晰的星河，下一步可以根据 RAG 评估数据的反馈（如命中某一领域的星星）修改 `nodeMaterial` 的**颜色**和**透明度**。例如：
- 当医疗数据命中时：将高亮节点的材质颜色（`nodeCol`）改为高亮的荧光绿，并调高该区域的 Bloom 强度。
- 当法律数据命中时：将颜色改为偏紫蓝色。
这会直观地在 3D 空间内形成“高亮星域”的动态反馈。
